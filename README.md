# Calculadora for Mac

The Mac app's installers and its automatic updates. The app's code lives elsewhere.

Download the latest version from [Releases](../../releases/latest):

- **Apple chip (M1 and newer):** `Calculadora-<version>-arm64.dmg`
- **Intel:** `Calculadora-<version>.dmg`

Needs macOS 13 or newer. Signed by PRIMEWILLCALL CORP and notarized by Apple. Once
installed, the app keeps itself up to date.
